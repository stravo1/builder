{# The document every extension frame loads. It is the same for every extension and every slot, so it takes no route parameter and needs no Python. The frame is sandboxed without allow-same-origin, so it runs at an opaque origin. The SDK learns which slot it is, and which entry to import, from the connect handshake the host sends. See docs/extensions/asset-serving.md. script-src names both 'self' and the site URL on purpose. 'self' covers a site reached on a second hostname, where the site URL would name the wrong origin. The site URL covers a browser that does not match 'self' at an opaque origin. #} Builder Extension
